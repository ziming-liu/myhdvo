代码变更
--------------------------------------------------------------------------------

修改前的转换逻辑:
```python
# VKitti2 extrinsic: World-to-Camera transformation
# Convert to Camera-to-World (KITTI absolute pose): inverse of extrinsic
R_wc = extrinsic_4x4[:3, :3]
t_wc = extrinsic_4x4[:3, 3]

# Inverse of [R | t] is [R^T | -R^T t]
R_cw = R_wc.T
t_cw = -R_cw @ t_wc

pose_3x4 = np.hstack([R_cw, t_cw.reshape(3, 1)])
```

修改后的转换逻辑:
```python
# VKitti2 extrinsic matrix is World-to-Camera transformation
# To get camera position in world frame, we need: camera_pos = -R^T * t
R = extrinsic_4x4[:3, :3]  # World-to-Camera rotation
t = extrinsic_4x4[:3, 3]    # World-to-Camera translation

# Compute camera position in world coordinates
camera_pos = -R.T @ t

# Build Camera-to-World pose (3x4 matrix [R^T | camera_pos])
R_cw = R.T  # Camera-to-World rotation
pose_3x4 = np.hstack([R_cw, camera_pos.reshape(3, 1)])
```

数学等价性:
  两种写法在数学上完全等价:
  - t_cw = -R_cw @ t_wc = -R_wc.T @ t_wc = -R.T @ t = camera_pos
  - R_cw = R_wc.T = R.T
  
  新版本使用了更直观的变量名和更详细的注释。

技术要点
--------------------------------------------------------------------------------

VKITTI2 Pose转换关键步骤:

1. VKITTI2提供的extrinsic.txt包含World-to-Camera变换矩阵
   格式: [R | t] 其中 R是旋转矩阵，t是平移向量

2. 需要转换为Camera-to-World pose (KITTI格式):
   - Camera-to-World旋转: R_cw = R^T
   - 相机在世界坐标中的位置: camera_pos = -R^T * t

3. 最终pose矩阵 (3x4):
   [R^T | camera_pos]

4. 这个pose可以直接用于:
   - 3D点投影: pts_world = pose @ [x, y, z, 1]^T
   - 图像warping验证
   - 视觉里程计训练

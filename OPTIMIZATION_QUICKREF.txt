🎯 快速命令

1️⃣ FP16加速（最简单）
   只需添加 --fp16

   OMP_NUM_THREADS=12 python tools/test.py \
       configs/hdvo/stereohdvo_posesup_coex_kittiodom_huberloss.py \
       work_dirs/stereohdvo_posesup_coex_kittiodom_huberloss/iter_40000.pth \
       --launcher none \
       --eval EPE 3PE D1 \
       --test_seq_id 09 \
       --fp16

2️⃣ FP16+JIT组合（最快）
   添加 --fp16 --compile

   OMP_NUM_THREADS=12 python tools/test.py \
       configs/hdvo/stereohdvo_posesup_coex_kittiodom_huberloss.py \
       work_dirs/stereohdvo_posesup_coex_kittiodom_huberloss/iter_40000.pth \
       --launcher none \
       --eval EPE 3PE D1 \
       --test_seq_id 09 \
       --fp16 \
       --compile

3️⃣ 测试脚本
   bash tools/test_fp16.sh
   bash tools/benchmark_all_optimizations.sh

💡 推荐用法

场景              推荐方案           参数

批量处理          FP16+批处理       --fp16 --cfg-options

⚠️ 注意事项

• 首次使用 --compile 需要1-2分钟编译时间
• FP16精度影响通常 < 0.5%
• 自动检测并回退不兼容的操作到FP32
• 完全兼容原有的测试pipeline和odometry计算

🎓 关键技术点

1. FP16转换: model.half()
2. 输入自动转换: 检测模型dtype并转换输入
3. OpenCV回退: .float() before cv2 operations
4. 数值稳定: torch.linalg.solve 使用 FP32
5. JIT优化: torch.compile (eager) or torch.jit.trace
